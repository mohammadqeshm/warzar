GAME CONTENT (original, created for this project)
- All 3D models (Commander, Nana, enemies, jeep, village kit, crates, plane, parachutes) are generated procedurally in code.
- All textures (camo, wood, stone, plaster, roof, sandbags, sprites, faces, decals, logo) are painted procedurally on <canvas> at runtime.
- All sound effects are synthesized at runtime with the WebAudio API. No audio files.
- The WARZAR logo is drawn at runtime on <canvas> from text. No fonts are bundled; the UI uses the system font stack
  (Impact, Haettenschweiler, Arial Narrow Bold, Franklin Gothic Heavy, Roboto Condensed, Arial Black, sans-serif-condensed).
- No real-world weapon brands, no social-media icons, no external links.
